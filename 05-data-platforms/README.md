# Module 5: Nền Tảng Dữ Liệu Hiện Đại (Data Platforms)

Trong module này, bạn sẽ tìm hiểu cách xây dựng và vận hành các nền tảng dữ liệu toàn diện (end-to-end data platform) bằng **Bruin** - một framework hiện đại tích hợp thu nạp dữ liệu, chuyển đổi dữ liệu và kiểm tra chất lượng dữ liệu (Data Quality) vào trong một công cụ duy nhất. Bạn cũng sẽ khám phá cách kết hợp **Bruin MCP (Model Context Protocol)** với các AI Agents và triển khai lên **Bruin Cloud**.
